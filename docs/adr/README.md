# Architecture Decision Records

Decisions are recorded in [Nygard format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)
(context, decision, alternatives, consequences). A new decision gets the next number. A changed
decision gets a new ADR that supersedes the old one, which keeps its text and is marked *Superseded*.
