# Changelog

All notable changes to this project are documented here. The format follows

From the first release on, entries are generated by release-please from Conventional Commits.

## [Unreleased]

### Added

- M1 domain core (`@kt/core`): zod schemas for patterns and projects, built-in symbol library
  (knit/purl, increases, decreases, bind-off, no-stitch, 12 cable crossings with derived stitch flow
  and DROPS number mapping), chart parsing, stage layout with partial horizontal repeats, independent
  vertical repeats, markers and sections, per-project chart replacement, progress engine for round and
  flat work (WS rows reversed and inverted), undo/redo reducer, text instructions per row,
  validation (structure, stitch-count chain, stitch-flow lint, partial repeats cutting cables, WS
  symbols, references), versioned pattern files with migrations. Unit, property-based and local
  golden tests.
- `docs/pattern-format.md`: pattern file format and diagnostics.
- Phase 0 analysis, requirements, risks and ADRs (`docs/00-analysis.md`, `docs/adr/`).
- M0 project skeleton: pnpm monorepo (`@kt/core`, `@kt/grid-renderer`, `@kt/importer`,
  `@kt/test-fixtures`, `@kt/web`), strict TypeScript, ESLint/Prettier, husky, lint-staged,
  commitlint, Vitest with a coverage gate, Playwright on four viewports with axe, a PWA shell with an
  offline service worker, a Docker image (nginx-unprivileged with CSP), compose profiles, a GitHub
  Actions CI, Renovate and release-please configuration, and a forbidden-content guard.
