# Frozen schema v2 files

Written once in the schema v2 file format (M5: a pattern with stages, a project tracking one
pattern) and **never regenerated**. Migration tests read them to prove that files from version
1.0 still open after the move to schema v3 (project → patterns → charts). When the schema changes
again, add a `v3/` folder next to this one instead of editing these.

The backup holds one project (with finished rows, a chart replacement, the knitter's gauge and
progress in two stages) and one pattern no project used.

Synthetic content only (R-5).
